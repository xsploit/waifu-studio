# Desktop motion attribution

`idle-maid.vrma`, `grabbed.vrma`, and `idle-sitting.vrma` are unchanged official Desktop Homunculus assets by notelm and contributors.

Source: https://github.com/not-elm/desktop-homunculus/tree/main/mods/assets/vrma

License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/ . Upstream README assigns this license to creative assets; the assets package declares MIT AND CC-BY-4.0.

Waifu Studio uses the standing idle, held, and seated idle clips with its own VRMA importer and humanoid retargeter. File contents are unmodified; playback retargets them to the selected avatar.
